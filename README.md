# Greeting-App
Greeting App lets users enter their name and favorite color to create a personalized greeting. Click Clear to reset the fields and start again.

Steps on how to use the App:
1. Open Greeting App.slnx in Visual Studio.
2. If Visual Studio asks, trust the project and let it finish loading.
3. Press F5 or click the green Start button.
4. The app window opens. You can now use it.
