# Greeting-App
Greeting App lets users enter their name and favorite color to create a personalized greeting. Click Clear to reset the fields and start again.


To open and run it in Visual Studio:
1. Open Visual Studio.
2. Choose Open a project or solution.
3. Select Greeting App.csproj from this folder. If you see Greeting App.slnx in the parent folder, you can open that instead.
4. Wait for the project to load, then press F5 or click the green Start button.
